QR 服务器设置

使用 QR 添加 Kavita 和 Komga 服务器

生成安全的 BiblioFuse 二维码用于 Kavita 或 Komga 服务器连接，然后从手机扫描以自动添加服务器。

生成您的二维码

在下方填写您的服务器信息，然后点击生成以创建可扫描的二维码。

从 Kavita 或 Komga 的用户/账户设置中复制 API 密钥。

此二维码包含您的服务器地址和身份验证信息。请勿公开发布。

二维码由 qrcode-generator 驱动

功能介绍

创建一个可共享的服务器 QR 码，包含 API 地址和可选密钥，让 BiblioFuse 无需手动输入 URL 即可连接。

  • 支持 Kavita 和 Komga API 服务器
  • 包含可选 API 密钥以确保安全连接
  • 适用于 iOS 和 Android 设备

使用方法

1

生成二维码

输入服务器地址，选择 Kavita 或 Komga，必要时添加 API 密钥。

2

在 BiblioFuse 中扫描

打开设置 > OPDS（专业功能）> 添加服务器，然后点击 QR 图标扫描二维码。

3

选择并阅读

在书库中，打开左上角的位置面板，选择您的服务器，享受阅读。

专业功能说明

服务器扫描流程需要 BiblioFuse Pro OPDS 功能。添加服务器后，使用位置选择器切换到您的 Kavita 或 Komga 书库。

快速提示

使用安全的私人网络或 Tailscale 进行远程访问。

生成 QR 前请仔细检查服务器 URL 和 API 密钥。

妥善保管生成的二维码，其中包含访问信息。
