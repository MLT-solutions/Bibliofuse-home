Configuration QR serveur

Ajoutez des serveurs Kavita et Komga par QR

Générez un code QR BiblioFuse sécurisé pour les connexions serveur Kavita ou Komga, puis scannez-le depuis votre téléphone pour ajouter le serveur automatiquement.

Générez votre code QR

Remplissez les informations de votre serveur ci-dessous, puis appuyez sur Générer pour créer un code QR scannable.

Copiez la clé API depuis les paramètres utilisateur/compte de Kavita ou Komga.

Ce code QR contient l'adresse de votre serveur et vos informations d'authentification. Ne le partagez pas publiquement.

Code QR généré par qrcode-generator

Ce que ça fait

Créez un QR serveur partageable avec votre adresse API et clé facultative, pour que BiblioFuse se connecte sans saisie manuelle d'URL.

  • Prend en charge les serveurs API Kavita et Komga
  • Inclut une clé API optionnelle pour des connexions sécurisées
  • Fonctionne sur iOS et Android

Comment l'utiliser

1

Générez le code QR

Entrez l'adresse de votre serveur, choisissez Kavita ou Komga, et ajoutez une clé API si nécessaire.

2

Scannez dans BiblioFuse

Ouvrez Réglages > OPDS (Fonction Pro) > Ajouter un serveur, touchez l'icône QR et scannez le code.

3

Sélectionnez et lisez

Dans Bibliothèque, ouvrez le panneau Emplacement en haut à gauche, choisissez votre serveur et profitez de la lecture.

Note fonction Pro

Le scan nécessite la fonction OPDS Pro de BiblioFuse. Une fois le serveur ajouté, utilisez le sélecteur Emplacement pour passer à votre bibliothèque Kavita ou Komga.

Conseil rapide

Utilisez un réseau privé sécurisé ou Tailscale pour l'accès à distance.

Vérifiez l'URL du serveur et la clé API avant de générer le QR.

Conservez le code généré en sécurité — il contient des informations d'accès.
