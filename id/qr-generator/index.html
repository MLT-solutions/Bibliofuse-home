Pengaturan server QR

Tambahkan server Kavita & Komga dengan QR

Buat kode QR BiblioFuse yang aman untuk koneksi server Kavita atau Komga, lalu pindai dari ponsel Anda untuk menambahkan server secara otomatis.

Buat kode QR Anda

Isi detail server Anda di bawah, lalu ketuk Buat untuk menghasilkan kode QR yang dapat dipindai.

Salin kunci API dari pengaturan pengguna/akun Kavita atau Komga.

Kode QR ini berisi alamat server dan informasi autentikasi Anda. Jangan bagikan secara publik.

Kode QR didukung oleh qrcode-generator

Fungsinya

Buat QR server yang dapat dibagikan dengan alamat API dan kunci opsional, sehingga BiblioFuse dapat terhubung tanpa mengetik URL manual.

  • Mendukung server API Kavita dan Komga
  • Termasuk kunci API opsional untuk koneksi aman
  • Bekerja di perangkat iOS dan Android

Cara menggunakannya

1

Buat kode QR

Masukkan alamat server Anda, pilih Kavita atau Komga, dan tambahkan kunci API jika diperlukan.

2

Pindai di BiblioFuse

Buka Pengaturan > OPDS (Fitur Pro) > Tambah server, lalu ketuk ikon QR dan pindai kode.

3

Pilih dan baca

Di Perpustakaan, buka panel Lokasi kiri atas, pilih server Anda, dan nikmati membaca.

Catatan Fitur Pro

Alur pemindaian server memerlukan fitur BiblioFuse Pro OPDS. Setelah server ditambahkan, gunakan pemilih Lokasi untuk beralih ke perpustakaan Kavita atau Komga Anda.

Tips cepat

Gunakan jaringan pribadi yang aman atau Tailscale untuk akses jarak jauh.

Periksa kembali URL server dan kunci API sebelum membuat QR.

Simpan kode yang dihasilkan dengan aman — berisi informasi akses.
