QR server setup

Add Kavita & Komga servers with QR

Generate a secure BiblioFuse QR code for Kavita or Komga server connections, then scan it from your phone to add the server automatically.

Generate your QR code

Fill in your server details below, then tap Generate to create a scannable QR code.

Copy the API key from Kavita or Komga user/account settings.

This QR code contains your server address and authentication information. Do not share it publicly.

QR code powered by qrcode-generator

What this does

Create a shareable server QR with your API address and optional key, so BiblioFuse can connect without manual URL typing.

  • Supports Kavita and Komga API servers
  • Includes optional API key for secure connections
  • Works on iOS and Android devices

How to use it

1

Generate the QR code

Enter your server address, choose Kavita or Komga, and add an API key if needed.

2

Scan in BiblioFuse

Open Settings > OPDS (Pro Feature) > Add server, then tap the QR icon and scan the code.

3

Select and read

In Library, open the top-left Location panel, choose your server, and enjoy reading.

Pro Feature note

The server scan flow requires the BiblioFuse Pro OPDS feature. Once the server is added, use the Location selector to switch to your Kavita or Komga library.

Quick tip

Use a secure private network or Tailscale for remote access.

Double-check the server URL and API key before generating the QR.

Keep the generated code safe — it includes access information.
