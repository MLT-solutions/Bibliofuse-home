QR 서버 설정

QR로 Kavita 및 Komga 서버 추가

Kavita 또는 Komga 서버 연결을 위한 안전한 BiblioFuse QR 코드를 생성하고, 휴대폰에서 스캔하여 서버를 자동으로 추가하세요.

기능 설명

API 주소와 선택적 키가 포함된 공유 가능한 서버 QR을 만들어, URL을 수동으로 입력하지 않고 BiblioFuse가 연결할 수 있습니다.

  • Kavita 및 Komga API 서버 지원
  • 보안 연결을 위한 선택적 API 키 포함
  • iOS 및 Android 기기에서 작동

사용 방법

1

QR 코드 생성

서버 주소를 입력하고 Kavita 또는 Komga를 선택한 후 필요한 경우 API 키를 추가하세요.

2

BiblioFuse에서 스캔

설정 > OPDS (Pro 기능) > 서버 추가를 열고 QR 아이콘을 탭하여 코드를 스캔하세요.

3

선택하고 읽기

라이브러리에서 왼쪽 상단의 위치 패널을 열고 서버를 선택한 후 독서를 즐기세요.

Pro 기능 참고

서버 스캔에는 BiblioFuse Pro OPDS 기능이 필요합니다. 서버를 추가한 후 위치 선택기를 사용하여 Kavita 또는 Komga 라이브러리로 전환하세요.

빠른 팁

원격 접근에는 안전한 개인 네트워크나 Tailscale을 사용하세요.

QR을 생성하기 전에 서버 URL과 API 키를 다시 확인하세요.

생성된 코드를 안전하게 보관하세요. 접속 정보가 포함되어 있습니다.
