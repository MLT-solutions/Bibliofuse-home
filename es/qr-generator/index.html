Configuración QR de servidor

Añade servidores Kavita y Komga con QR

Genera un código QR seguro de BiblioFuse para conexiones con servidores Kavita o Komga, y escanéalo desde tu teléfono para añadir el servidor automáticamente.

Qué hace

Crea un QR de servidor compartible con la dirección API y clave opcional, para que BiblioFuse se conecte sin escribir URLs manualmente.

  • Compatible con servidores API Kavita y Komga
  • Incluye clave API opcional para conexiones seguras
  • Funciona en dispositivos iOS y Android

Cómo usarlo

1

Genera el código QR

Introduce la dirección de tu servidor, elige Kavita o Komga y añade una clave API si es necesario.

2

Escanea en BiblioFuse

Abre Ajustes > OPDS (Función Pro) > Añadir servidor, luego toca el icono QR y escanea el código.

3

Selecciona y lee

En Biblioteca, abre el panel Ubicación arriba a la izquierda, elige tu servidor y disfruta de la lectura.

Nota de función Pro

El flujo de escaneo requiere la función OPDS Pro de BiblioFuse. Una vez añadido el servidor, usa el selector Ubicación para cambiar a tu biblioteca Kavita o Komga.

Consejo rápido

Usa una red privada segura o Tailscale para acceso remoto.

Verifica la URL del servidor y la clave API antes de generar el QR.

Guarda el código generado de forma segura, contiene información de acceso.
